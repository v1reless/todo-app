# Todo-лист

Небольшой список задач на чистом HTML, CSS и JavaScript.

## Демо

После публикации:

https://v1reless.github.io/todo-app/

## Что умеет

- добавлять задачи;
- отмечать выполненные;
- удалять задачи;
- фильтровать: все, активные, выполненные;
- удалять все выполненные задачи;
- сохранять задачи в `localStorage`;
- синхронизировать список между вкладками.

## Стек

- HTML
- CSS
- JavaScript
- localStorage

Без фреймворков, CDN и сборщиков.

## Как запустить

Открыть `index.html` в браузере или использовать Live Server в VS Code.

Для полноценной проверки лучше запустить локальный сервер:

```powershell
python -m http.server 8000
```

И открыть:

```
http://localhost:8000
```

## Структура

- `index.html` — разметка;
- `style.css` — стили;
- `script.js` — логика;
- `favicon.svg` — иконка;
- `AGENTS.md` — правила для AI-агента.
